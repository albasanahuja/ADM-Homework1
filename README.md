# Algorithmic Methods of Data Mining - Homework 1

This repository contains the submissions and solutions for Homework 1 of the Algorithmic Methods of Data Mining course.

## Repository Contents:

* `scripts.py`: A Python file containing all the source code for the completed HackerRank challenges, clearly organized and separated by topic.
* `printouts/`: A folder containing the visual proofs of completion. Inside, you will find:
  * `Submissions _ HackerRank.pdf`: A comprehensive PDF generated from the HackerRank submissions page, showing the "Accepted" status and scores for all the solved challenges.
  * `Screenshots`: Multiple individual image files capturing the successful completion of the exercises, provided as additional supporting evidence as requested in the guidelines.
